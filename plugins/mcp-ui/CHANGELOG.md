# 变更记录

## 0.2.0（2026-11-16）

- 新增：每个工具可以在设置页被禁用（「启用」勾选框，默认全部启用）。配置项 `disabledTools` 保存完整工具名或以 `*` 结尾的前缀，实时生效，不需要重载插件。
- 新增：服务 `mcpDisabled`（`isDisabled(name)`），供 Code Mode 在 Code Mode 预设下隐藏被禁用的工具。读取失败时视为没有禁用，不抛错。
- 新增：`tools/pre-execute` 监听器拒绝被禁用工具的调用，返回的拒绝文本为「工具 <name> 已被用户在 MCP 设置里禁用。」。这是所有执行器共用的唯一拒绝路径。
- 界面：被禁用的工具行变淡，其「支持并行」勾选框不可用；被前缀规则禁用的工具显示「由 <前缀> 禁用」，且「启用」框锁定。工具区出现一行说明：Code Mode 下被禁用的工具不会出现在模型的工具列表里，其他预设下模型仍能看到它，但调用会被拒绝。
- core：新增 `toggleDisabled`（返回新列表，不修改输入；前缀仍覆盖时报告前缀而不编辑）和 `isDisabled`。精确匹配与前缀匹配与并行名单共用同一个匹配函数。

## 0.1.10（2026-11-16）

- 界面：去掉头部的「工具 · N」按钮。点击服务器名那一块（箭头、状态点、名称、传输方式、状态）展开或折叠工具列表。服务器没连上时没有工具可折叠，这一块不可点。

## 0.1.9（2026-11-16）

- 界面：去掉「工具 · N」那一行和底部的按钮行。卡片头部一行放：状态、「全部支持并行」（展开时）、「工具 · N」折叠按钮、重启、编辑、删除、启用开关。窗口窄时头部自动换行。

## 0.1.8（2026-11-16）

- 界面：每个服务器的工具列表默认折叠，只显示「工具 · N」；点开后才显示工具、描述和「支持并行」勾选。

## 0.1.7（2026-11-16）

- 界面：页面顶部的三条提示合并成一行，窗口太窄时省略号截断。

## 0.1.6（2026-11-16）

- 修复：`mcpTools` 服务缺少 DSH 网关要求的 `typertRemote` 绑定，页面报 `Service "mcpTools" has no visible typertRemote binding`。服务改为带绑定字段的类（`tools-service.ts`），并加测试。

## 0.1.5（2026-11-16）

- 修复：0.1.4 的 Typert 描述文件缺少服务的 `types` 数组，DSH 的 typert-loader 拒绝注册，桌面版启动时报 `desktop welcome: Web RPC failed` 并无法打开。补上 `types: []`，并加回归测试固定描述文件的格式。0.1.4 不要安装。

## 0.1.4（2026-11-16）

- 新增：每个工具名下显示它的描述（模型看到的那段文字），超过 600 字符截断。
- 变更：页面只订阅 mcp-ui 自己的一个流 `mcpTools.watch`，同时拿到服务器状态、工具和描述；不再调官方的 `watch` 和 `probe`。工具直接取自宿主的工具注册表，不再为读取工具名另开一条到服务器的连接。
- 变更：服务器没有启用或没有连上时，不显示工具，提示「启用并连接后显示这个服务器提供的工具」。之前可以对停用的服务器探测工具。
- 新增：设置弹窗整体放大（宽最大 1280px，高接近窗口高度），MCP 页面不再限制 760px 宽。
- 内部：新增手写的 Typert 描述文件（`./typert` 导出，浏览器端用 `$mount` 挂载）。构建依赖新增 `@deepseek-ai/dsh-typert-protocol` 与 `zod`，都只打进包里，不是运行时依赖。

## 0.1.3（2026-11-16）

- 界面：每个服务器是一张卡片，名称、传输方式、状态和启用开关在头部，工具直接列在卡片下面，每个工具一个「支持并行」勾选框。连接成功后自动读取工具，不再需要点「工具」按钮。
- 界面：补上样式表，使用 DSH 的主题变量，浅色和深色主题都跟随。之前页面没有样式，文字挤在一起。
- 状态点按连接状态着色（已连接、连接中、失败、已停用）。

## 0.1.2（2026-11-16）

- 修复：工具的「支持并行」勾选保存的是服务器原始工具名（`slow`），而 code-mode 判定并行用的是完整名（`mcp__echo__slow`），勾选不会生效。现在保存完整名。旧版本留在名单里的原始名不再显示为已勾选。

## 0.1.1（2026-11-16）

- 修复：浏览器端 `inject` 漏了 `remote.mcpManager`，页面报 `cannot get property "remote.mcpManager" without inject`，服务器列表与探测都无法使用。
- 修复：探测失败时显示管理器返回的真实原因，不再只显示「探测失败」。
- 修复：服务器名不允许包含双下划线，否则 `mcp__fs__*` 会误匹配服务器 `fs__x` 的工具。

## 0.1.0（2026-11-16）

- 新增 DSH 设置页「MCP」标签：列出服务器、实时状态、工具数，支持启停、重启、增删改。
- 新增每个工具的「支持并行」勾选，以及「全部工具」勾选（`mcp__<server>__*`）。
- 新增宿主侧配置 `parallelTools`（volatile，保存后立即生效），并提供服务 `mcpParallel`。
- 新增 core：服务器条目校验（对齐官方 mcp-manager 的写入规则）、并行名单的匹配与增删、工具名解析。
