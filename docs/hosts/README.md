# 宿主笔记

每个目标宿主一份笔记，记录写 adapter 需要的事实。规则：

1. 每条事实带来源链接；能在本机验证的写验证命令。
2. 顶部写"核对版本"和"核对日期"。宿主升级后重新核对，并更新这两项。
3. 只记事实和本项目的用法约定。选择性的决定写 ADR，踩坑写 `friction.md`，修复后把结论回写到这里。

## 模板

```markdown
# <宿主名>

- 核对版本：
- 核对日期：
- 官方文档：
- 稳定性：（稳定 / 预览，有无破坏性变更承诺）

## 插件形态
## 注册工具
## 拦截工具调用
## 其他扩展点（命令、skills、UI…）
## 打包与安装
## 本地验证命令
## 本项目约定
## 已知问题
```
